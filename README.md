# Простой Калькулятор

Это простой калькулятор, созданный на Python с использованием библиотеки `tkinter`. Он разработан с упором на доступность и простоту использования.

## Как запустить на macOS

Для запуска калькулятора не требуются дополнительные библиотеки, так как `tkinter` входит в стандартную поставку Python.

1.  Откройте терминал.
2.  Перейдите в директорию с проектом.
3.  Выполните следующую команду:

    ```bash
    python3 calculator/main.py
    ```
