# Доступный калькулятор

Это простой и доступный калькулятор, созданный на Python с использованием библиотеки tkinter.

## Особенности

*   **Высококонтрастная темная тема:** для комфортного использования при слабом освещении.
*   **Большие кнопки и шрифты:** для удобства использования на сенсорных экранах и людьми с нарушениями зрения.
*   **Полное управление с клавиатуры:** для тех, кто предпочитает использовать клавиатуру.
*   **Безопасность:** выражение вычисляется с помощью безопасного парсера AST, а не `eval()`.

## Как запустить

Для запуска калькулятора убедитесь, что у вас установлен Python 3 и `tkinter`.

1.  Клонируйте репозиторий.
2.  Перейдите в корневую директорию проекта.
3.  Выполните команду:
    ```bash
    python3 -m calculator.main
    ```
