# Калькулятор

Это простой, доступный калькулятор, созданный с использованием Python и `tkinter`.

## Особенности

*   **Высококонтрастная темная тема** для лучшей читаемости.
*   **Большие кнопки и шрифты** для удобства использования.
*   **Поддержка клавиатуры** для всех основных функций.
*   **Безопасное вычисление выражений** с использованием `ast` для предотвращения уязвимостей.

## Как запустить

Для запуска калькулятора убедитесь, что у вас установлен Python 3 и `tkinter`.

```bash
python3 -m calculator.main
```
