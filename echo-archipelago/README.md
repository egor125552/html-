# Эхо-Архипелаг

Доступный браузерный прототип кооперативной аудио-игры про спасение на лодке.

## Что уже работает

- Управление лодкой с инерцией, течением и удержанием кнопок.
- Отдельный режим для VoiceOver: нажатия дают короткие импульсы вместо обязательного удержания.
- Пространственный сонар с направлением и расстоянием.
- Топливо, нагрузка, перегрев и ремонт двигателя.
- Повреждения корпуса, течь, вода и насос.
- Спасательный трос: нужно подойти близко, сбросить скорость и удерживать действие.
- Одиночная адаптация с помощником.
- Кооператив капитан/оператор через две вкладки (BroadcastChannel).
- Экспериментальный интернет-кооператив через PeerJS/WebRTC.

## Запуск

```bash
python3 -m http.server 4173
```

Открой `http://localhost:4173`.

## Деплой Cloudflare

```bash
npm install
npx wrangler login
npm run deploy
```

## Управление

Телефон без VoiceOver: удерживай фиксированные зоны руля, газа, тормоза, насоса и троса.
С VoiceOver: включи соответствующий режим; обычное нажатие на рулевую кнопку создаёт короткий импульс.
ПК: стрелки, S, пробел, P и R.
