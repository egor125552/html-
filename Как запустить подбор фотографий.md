# Движение товара с фотографиями

Этот проект сопоставляет товары в файле Движение товара.xlsx с тремя каталогами Garfield и добавляет ссылки на фотографии. Все исходные количества и расчёты остаются на своих местах.

Для нового запуска положите рядом четыре исходных файла и выполните команду:

python3 merger.py

Программа не требует установки дополнительных библиотек и не скачивает фотографии из интернета. Она берёт существующие ссылки из каталогов.

После запуска появятся четыре файла:

- Движение товара с фотографиями.xlsx. Исходная таблица плюс фотография, статус проверки, оценка сходства, название, артикул и адрес товара.
- Отчёт о сопоставлении.csv. Проверка каждой строки, удобно открывать в Excel.
- Товары для проверки.csv. Список сложных и не найденных позиций с возможными альтернативами.
- Итоги подбора фотографий.txt. Краткие результаты для чтения VoiceOver.

Значения статуса:
- Надёжно: существенные признаки совпали, а другая карточка заметно хуже.
- Вероятно: хороший кандидат, но некоторые сведения в каталоге неполные.
- Проверить: программа нашла фотографию, но остаётся риск ошибки. Эти строки нельзя без проверки автоматически выдавать за точно установленные совпадения.
- Нет совпадения: программа не смогла доказательно подобрать товар.
- Пропущено: пустая или служебная строка.

Особенность исходных каталогов: многие названия **не содержат веса упаковки**, хотя он есть в ведомости. Поэтому совпадение линейки товара само по себе не доказывает, что изображена упаковка нужного размера. Если размер отсутствует у товара в каталоге, это отмечается в колонке Обоснование.

Чтобы запустить проверки отдельно:

python3 -m unittest -v test_merger

Как устроена программа: чтение и запись таблиц, подбор фотографий и запуск процесса находятся в независимых частях. Можно дорабатывать один из способов поиска, не изменяя исходную книгу.

Для повторного запуска измените исходные файлы и выполните python3 merger.py на компьютере с Python 3. После этого откройте полученный Excel.
