# Движение товара с фотографиями

Этот проект сопоставляет товары в файле Движение товара.xlsx с тремя каталогами Garfield и добавляет ссылки на фотографии. Все исходные количества и расчёты остаются на своих местах.

Для нового запуска положите рядом четыре исходных файла и выполните команду:

python3 merger.py

Программа не требует установки дополнительных библиотек и не скачивает фотографии из интернета. Она берёт существующие ссылки из каталогов и сохранённые ссылки из официальной карты фотографий Garfield.

После запуска появятся пять файлов:

- Движение товара с фотографиями.xlsx. Исходная таблица плюс фотография, статус проверки, оценка сходства, название, артикул и адрес товара.
- Отчёт о сопоставлении.csv. Проверка каждой строки, удобно открывать в Excel.
- Товары для проверки.csv. Список сложных и не найденных позиций с возможными альтернативами.
- Итоги подбора фотографий.txt. Краткие результаты для чтения VoiceOver.
- Найденные фото Garfield.csv. Проверенные по совпадению названий ссылки из карты официального сайта, которые можно повторно использовать.

Значения статуса:
- Надёжно: существенные признаки совпали, а другая карточка заметно хуже.
- Вероятно: хороший кандидат, но некоторые сведения в каталоге неполные.
- Проверить: программа нашла фотографию, но остаётся риск ошибки. Эти строки нельзя без проверки автоматически выдавать за точно установленные совпадения.
- Нет совпадения: программа не смогла доказательно подобрать товар.
- Пропущено: пустая или служебная строка.

Особенность исходных каталогов: многие названия **не содержат веса упаковки**, хотя он есть в ведомости. Поэтому совпадение линейки товара само по себе не доказывает, что изображена упаковка нужного размера. Если размер отсутствует у товара в каталоге, это отмечается в колонке Обоснование.

Чтобы запустить проверки отдельно:

python3 -m unittest -v test_merger

Как устроена программа: чтение и запись таблиц, подбор фотографий и запуск процесса находятся в независимых частях. Можно дорабатывать один из способов поиска, не изменяя исходную книгу.

Для повторного запуска измените исходные файлы и выполните python3 merger.py на компьютере с Python 3. После этого откройте полученный Excel.

## Дополнительный поиск по фотографиям Garfield

При необходимости вручную сохраните официальный файл https://garfield.by/sitemap_img.xml в папку проекта под именем sitemap_img.xml и повторно выполните python3 merger.py. Программа прочитает названия страниц и фотографии, сохранит только подходящие ссылки в отдельном файле Найденные фото Garfield.csv. Исходный список сайта не копируется в GitHub. После этого программа сможет использовать найденные ссылки и без доступа к сайту.

Основная колонка URL фотографии содержит ссылку на изображение из S3 либо с официального Garfield; источник показан отдельно. Не считайте фотографию подтверждённой, если строка имеет статус Проверить. В частности, одна карточка может относиться к нескольким размерам упаковки.

## Дополнительные проверки

Программа различает дробные дозировки (например, 5,4 и 5,5 мг) и точные объёмы (например, 0,5 и 0,8 мл). Включён отдельный поиск по уникальным названиям товарных серий, который не заменяет проверку веса упаковки. Такие новые совпадения получают статус «Проверить».

Подбор по редкому названию серии отмечается отдельно. Для товаров с похожими названиями, но разными вкусами, породами, цветами или героями игрушек действует запрет на автоматическую подмену. Названия и дозы ветеринарных препаратов сравниваются строже. Ссылки на картинки со знаком пробела или кириллицей в пути записываются в безопасном URL-формате.
