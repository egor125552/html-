Gemini Озвучка текста

Продвинутый инструмент для преобразования текста в речь с настройками голоса, созданный для всех.

1. Введите текст

Вы можете управлять стилем речи прямо в тексте. Например, попробуйте написать:
(Say in a happy tone) Привет, мир! или (Говорить шепотом) Это секрет.

Идет генерация...

2. Выберите голос

Используйте стрелки для навигации, Space для прослушивания примера и Enter для выбора голоса.

Zephyr ▼

Дополнительная информация

Скорость вашего соединения: неизвестно

Примерное время генерации: 0 секунд

Рекомендуемая скорость интернета

Для комфортной работы приложения рекомендуется скорость соединения от 1 Мбит/с. При более низкой скорости возможны задержки.
